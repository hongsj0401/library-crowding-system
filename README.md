
# 도서관 혼잡도 공유 시스템
------------------------------

## 프로젝트 소개
도서관 열람실의 혼잡도를 계산하고 이용 현황을 확인할 수 있는 프로그램입니다.

## 개발 목적
사용자가 열람실의 혼잡도를 확인하여
보다 효율적으로 학습 공간을 선택하도록 돕습니다.

## 주요 기능
- 열람실 이용률 계산
- 혼잡도 단계 표시


## 개발 환경
- Python 
- Git
- GitHub

## 실행 방법
1. Python 을 설치합니다.
2. 저장소를 내려받습니다.
3. 터미널에서 다음 명령어를 실행합니다.

```bash
python src/main.py
```
